# Harris-Ferguson/homebrew-tap

```bash
brew install harris-ferguson/tap/paperclone
brew install harris-ferguson/tap/claudeboard
```

| Formula | Description |
|---|---|
| [paperclone](https://github.com/Harris-Ferguson/paperclone) | Menu-bar app that lays a subtle paper-texture overlay over the screen |
| [claudeboard](https://github.com/Harris-Ferguson/claudeboard) | Terminal control panel for Claude Code background sessions |
